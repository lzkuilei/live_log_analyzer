# 好好用用的直播日志分析工具

解析抖音直播实时数据日志（TXT），自动识别场次，生成交互式分析页面与导出报告。

## 功能

- **场次识别**：按「开播 → 同主播第一个下播」配对；重复开播视为断线重连；无配对下播线时按时间断层（10 分钟）自动切场；跨天直播归属开播当天
- **单场分析**：核心指标卡片、粉丝转化漏斗、关键事件检测（在线人数骤增/骤降，图上标注）、交互式波形图（悬停查看具体时间数值）
- **场次对比**：同主播全部场次横向对比，自动标出表现最好的一场
- **时段分析**：按开播时段（早/下午/晚/深夜）统计平均表现
- **导出**：单场/场次对比/时段分析 PDF（reportlab 生成）；汇总与原始数据 Excel（openpyxl）

## 网页版用法

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开提示的地址（默认 `http://localhost:8501`），左侧边栏上传日志 TXT，按「主播 → 日期 → 场次」筛选查看。

## exe 版用法

直接双击 `LiveLogAnalyzer.exe`（需 `_internal` 文件夹在同一目录），约 5 秒后自动打开浏览器。

- 端口自动选择（默认从 8501 起，被占用则顺延），控制台会显示实际端口
- 服务意外退出会自动重启（最多 5 次）
- 分发时请把整个 `LiveLogAnalyzer` 文件夹一起拷贝，不要只拷 exe

## 日志格式

```
2026-03-30 14:06:16	主播“某某主播”（房间号：1234567890123456） 03-30 14:05:48 已开播
2026-03-30 14:06:16	主播“某某主播”实时数据（房间号：1234567890123456），在线人数：0，总观看人数：0，点赞数：0，新增粉丝数：0
2026-03-30 16:22:47	主播“某某主播”已下播（房间号：1234567890123456），下播时间：03-30 16:22:37，直播时长：2小时16分49秒，本场直播总观看人数：0，点赞数：0，新增粉丝数：
```

（主播名、房间号为脱敏占位）

## 重新打包 exe

```bash
python pack.py
```

产物在 `build_pack/dist/LiveLogAnalyzer/`。源码以混淆形式打包进 exe。
